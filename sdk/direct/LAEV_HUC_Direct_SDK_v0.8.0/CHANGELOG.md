# Changelog

## 0.8.0 — HUC Direct SDK

- Python SDK package for issuance, renewal, revocation, offline verification and direct challenge-response.
- Optional FastAPI adapter for enterprise/education issuer and verifier integration.
- Android Kotlin library with Android Keystore key generation, PKCS#10 CSR, offline HUC package verification and direct holder proof.
- OkHttp API adapter for Android relying-party calls.
- TypeScript REST client and enterprise/education examples.
- OpenAPI 3.1 specification.
- Replay nonce storage with expiry-aware entries and concurrent locking.
- External trust pin, X.509/HUC-CC/state binding and freshness checks.
